# 🎲 DicoBot (디스코드 올인원 엔터테인먼트 봇)

Node.js와 `discord.js v14`로 제작된 **팀 분배 & 음성방 이동**, **코인 경제 & 노가다**, **블랙잭**, **텍사스 홀덤**을 지원하는 다기능 디스코드 봇입니다.

---

## ✨ 주요 기능

### 1. 🎲 팀 나누기 & 음성 채널 자동 이동 (`/팀나누기`)
- **자동 팀 분배**: 2 ~ 8팀 선택 가능 (직접 입력 또는 음성 채널 참여자 자동 감지)
- **음성 채널 자동 분리 🚀**:
  - `[음성 채널 분리 🚀]` 버튼을 누르면 봇이 팀별 임시 음성방(`🔴 1팀`, `🔵 2팀` 등)을 즉시 만들고 팀원들을 자동 이동시킵니다.
- **원래 방으로 모이기 📢**:
  - `[원래 방으로 모이기 📢]` 버튼을 누르면 모든 인원을 원래 통화방으로 복귀시키고 임시 채널을 자동 삭제 정리합니다.
- **다시 섞기 🔄**: 버튼 하나로 즉시 재추첨

---

### 2. 🪙 가상 코인 경제 시스템
- **신규 가입 지원**: 첫 이용 시 기본 **10,000 코인** 자동 지급
- **`/돈`**: 현재 내가 보유 중인 코인 잔액 확인
- **`/일일지원금`**: **매일 자정(00:00 KST)마다 초기화**되며, 하루 한 번 **5,000 코인**을 무료 지급
- **`/노가다`**:
  - 화면에 생성된 **`[곡괭이질 하기! ⛏️]`** 버튼을 연타하여 코인을 채굴!
  - **기본 보상**: 1 클릭당 **+1 코인**
  - **대박 잭팟(3% 확률)**: 낮은 확률로 **+100 코인** 잭팟 지급!

---

### 3. 🎰 코인 베팅 게임 (`/도박`)
- **명령어**: `/도박`
- **방식**: 명령어를 입력하면 **드롭다운 선택 메뉴**가 출력되며, 원하는 게임을 선택하면 배팅 금액 설정(모달) 후 게임이 시작됩니다!
  - 🃏 **블랙잭 (Blackjack)**: 딜러(봇)와 1:1 진검승부! (히트, 스탠드, 더블다운 지원)
  - ♠️ **텍사스 홀덤 (Texas Holdem)**: 2~6인 실시간 포커 테이블 개설 (빅블라인드 설정, 레이즈 모달 팝업, 연속 핸드 지원)
  - *(추후 룰렛, 슬롯머신 등 다양한 도박 게임이 드롭다운에 계속 추가될 예정입니다)*

---

### 4. 🎮 파티 & 추리 미니게임 (`/미니게임`)
- **명령어**: `/미니게임`
- **방식**: 명령어를 입력하면 **드롭다운 선택 메뉴**가 출력되며, 원하는 게임을 선택하면 대기실로 즉시 전환됩니다!
  - 🕵️‍♂️ **마피아 게임**:
    - **4~12인 지원 정통 마피아 게임**
    - **🎧 음성 채널 연동**: 게임 시작 시 전용 음성방 자동 개설 및 참가자 일괄 자동 이동
    - **🔇 밤낮 마이크 자동 제어**: 밤에는 전원 서버 음소거, 낮에는 생존자만 마이크 오픈
    - **👻 사망자 관전 & 비밀 유령방**: 사망자는 음성에서 마이크가 닫힌 채 관전하며, 사망자 전용 비밀 텍스트방(`👻-마피아-사망자-유령방`)에서 자유롭게 수다 가능
    - **🎭 커스텀 직업 (ON/OFF)**: 정치인(2표&처형면책), 사립탐정(야간미행), 군인(방탄복1회), 영매(사망자 유령방 엿보기)
    - **⚙️ 대기실 드롭다운 룰 설정**: 첫날 밤 마피아 킬(허용/금지), 의사 자힐 방식(무제한/1회/불가), 사망자 직업 공개 여부(공개/비공개), 커스텀 직업 ON/OFF 설정
  - *(추후 코인 없는 파티/추리 미니게임들이 드롭다운에 계속 추가될 예정입니다)*
  - **낮 토론 & 재판**:
    - 밤 결과 브리핑 ➔ 자유 토론 ➔ **1차 용의자 지목 투표** ➔ **최후의 변론** ➔ **처형 찬반 투표** (과반 찬성 시 처형)
    - 시민 전멸 or 마피아 전원 색출 시 승리 발표 및 전체 정체 공개!

---

### 5. 🖼️ SVG 이미지 렌더러 (`/svg` & 채팅 자동 감지)
- **`/svg` 명령어**:
  - `.svg` 파일을 첨부하거나 직접 SVG 코드를 입력하면 선명한 PNG 이미지로 변환하여 임베드로 출력합니다.
  - 1배, 2배(추천), 3배 초고화질 배율 선택 지원
- **채팅창 자동 감지**:
  - 채팅방에 `.svg` 파일을 드래그 앤 드롭으로 업로드하기만 해도 봇이 자동으로 PNG 렌더링 미리보기 이미지를 답장합니다.

---

## ⚙️ 필요한 봇 권한

음성 채널 자동 이동 기능을 사용하기 위해 봇 역할(Role)에 다음 권한이 필요합니다:
- **채널 관리 (Manage Channels)**: 임시 팀 음성방 생성 및 삭제
- **멤버 이동 (Move Members)**: 팀원들을 해당 음성 채널로 이동

---

## 🚀 실행 방법

### 1. 토큰 설정 ([.env](file:///.env))
```env
DISCORD_TOKEN=발급받은_디스코드_봇_토큰
CLIENT_ID=애플리케이션_ID(선택사항)
```

### 2. 봇 실행
```bash
npm start
```
